E-Commerce Sales Analysis using Python

Project Overview

This project analyzes an e-commerce sales dataset using Python. The goal was to clean the data, perform exploratory data analysis (EDA), create visualizations, and identify useful business insights.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Key Insights

- Identified the highest-selling products.
- Analyzed monthly revenue trends.
- Compared payment methods and referral sources.
- Explored customer purchasing behaviour.
- Suggested business recommendations based on the analysis.

Files Included

- EDA Notebook (.ipynb)
- Dataset (.xlsx)
- Images (if applicable)

Skills Demonstrated

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insight Generation
